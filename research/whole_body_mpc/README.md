# Whole-Body MPC

**Scope:** deterministic coordinated control of the AgileX Scout 2.0 differential-drive base and Piper 6-DoF arm.

Primary research questions:
- non-holonomic base + arm optimization;
- geometry-only reachability and obstacle avoidance;
- manipulability-aware arm/base coordination;
- GPU-parallel MPC / MPPI feasibility on Jetson AGX Orin;
- deterministic baseline for Piper-JEPA.

This track should establish the strongest geometry-based controller before learned predictive costs are introduced.

**Status:** research-plan document not yet expanded. System sequencing is defined in `../../ROADMAP.md`.
